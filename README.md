# Akan Name Generator

## 📌 Project Name
Akan Name Generator

---

## 📖 Project Description
The Akan Name Generator is a web application that calculates the day of the week a user was born and assigns them a traditional Akan name based on their gender. The names are derived from Ghanaian culture, where children are named according to the day of the week they were born.

## 📊 BDD (Behavior Driven Development)

| Input | Behavior | Output |
|------|----------|--------|
| Valid date + Male gender | Calculates day of week | Returns male Akan name |
| Valid date + Female gender | Calculates day of week | Returns female Akan name |
| Empty date | Shows alert | "Please enter a valid date" |
| No gender selected | Shows alert | "Please select gender" |
